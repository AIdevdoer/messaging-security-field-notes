# Unlimited Devices Turns Into a Review Habit

X says there is no limit to the number of devices that can use Chat. That is convenient for someone moving between a phone, a browser, a tablet, and the separate X Chat app. It also means "How many devices can I use?" has a second question hiding behind it. Which devices still have access?

The current help page explains that logging out removes private keys and conversation keys from the device, with an exception for the device-managed passcode option on iOS. It also says encrypted messages are deleted from the current device when the user logs out, while other logged-in devices are unaffected. If both the X app and the X Chat app are signed in on one device, the user must sign out of both to remove messages there.

Those details make device review a routine maintenance task. A laptop borrowed for a trip, an old browser profile, or a second phone can remain part of the account long after it stops being memorable. Encryption protects the route between approved endpoints. It does not notice that an endpoint is sitting in a drawer or now belongs to someone else.

Signal's August 4 update offers useful context. Signal expanded linked-device support so another Android phone or tablet can join an account, and its announcement puts the device-linking action in front of the user. The products use different systems, but both make the device list part of the security boundary.

Before adding another screen, check the existing sessions, remove anything unfamiliar, and decide whether the extra endpoint is worth maintaining.
